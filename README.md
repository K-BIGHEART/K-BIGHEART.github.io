# k-bigheart.github.io

Public address of the K-BIGHEART Laboratory Homepage: **https://k-bigheart.github.io**

This repository only contains a small page that shows the lab's Google Apps Script web app in a full-screen frame
(so Google's "created by a Google Apps Script user" banner is not shown). The site's code lives in a separate private repository.

To point it at a different web app deployment, change the `/exec` URL in `index.html` (two places).
